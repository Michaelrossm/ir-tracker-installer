# Mitwirken / Contributing

## Deutsch

Bitte Änderungen klein halten, beide Sprachen aktualisieren und vor einem Pull Request
alle Unit-Tests sowie mindestens den Simulationsablauf ausführen. Neue Hardwareprofile
brauchen reproduzierbare Fingerprints und dürfen keine proprietäre Firmware enthalten.

## English

Keep changes focused, update both languages, and run all unit tests plus at least the
simulation flow before opening a pull request. New hardware profiles require
reproducible fingerprints and must not contain proprietary firmware.
