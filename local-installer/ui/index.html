5 · Custom-Firmware installieren

Standardmäßig wird die integrierte und per SHA-256 geprüfte Firmware verwendet. Alternativ kann eine lokale ESP32-C3-App gewählt oder ein signiertes Paket aus dem neuesten GitHub-Release geladen werden.

Firmwarequelle wird nach der Kompatibilitätsprüfung angezeigt.

Achtung: Eine fremde unsignierte BIN kann nur auf ausdrücklichen Wunsch installiert werden. ESP-Typ und Partitionsgröße werden geprüft, der Inhalt kann aber nicht als vertrauenswürdig bestätigt werden.
